# BRANCH Sales Reporter A mobile-responsive web application designed for Accupoint Systems Incorporated merchandisers to streamline daily sales reporting, MTD (Month-to-Date) calculations, and Viber-formatted report generation. ## Features - **Branch Selection & Management:** Easy selection of specific NBS branches directly from the main menu. - **Daily Sales Encoder:** Input daily quantities and sales amounts with an optional **"No Sales"** toggle for zero-sales days. - **Automatic MTD Computation:** Automatically tracks and calculates Month-to-Date performance using local storage. - **Viber-Formatted Output:** Generates clean, ready-to-copy report formats optimized for mobile messaging apps like Viber. - **PDF Export & Large Viewer:** Built-in PDF report generator and full-screen view for easy reading and documentation. - **Offline Persistence:** Uses browser `localStorage` to retain user inputs and history securely on the device. ## Version & Credits - **App Name:** NBS Sales Reporter - **Company:** Accupoint Systems Incorporated - **Developer/Version:** Richard Jamag (Merchandiser) ## How to Use 1. Open the live web app link on your mobile browser (Google Chrome or Safari). 2. Tap the browser menu (`...`) and select **"Add to Home screen"** or **"Create shortcut"** for quick app-like access. 3. Select your assigned branch from the main menu. 4. Input your daily sales data or check the **"No Sales"** option if applicable. 5. Copy the generated Viber report or download the PDF summary.
